01 / About

About me

I'm interested in both sides of security: how systems break, and how you'd notice when they do. Most of what I've built sits somewhere between the two.

On the offensive side, I've worked through every SQL injection lab on PortSwigger's Web Security Academy and built a recon tool that maps a domain's external exposure in one run. On the defensive side, I built HoneyTrap, a platform that plants fake credentials and alerts the moment anyone touches them, and an insider threat detector that works like a small SIEM.

In May and June 2026 I was a Data Security Intern at Visit Health. I built the recon pipeline shown below, contributed to a vendor cloud security audit (logging, network security, IAM and S3 data protection), analysed security logs in Splunk and ELK, and hardened AWS infrastructure with IAM policies, security groups, CloudTrail and GuardDuty.
